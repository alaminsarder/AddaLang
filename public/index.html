Shob keyword ek nojore

        
Chhoto language, tai mathay rakha shohoj.

      

      

        
adda shuruadda shesh
Program shuru ar shesh. Er baire ja thakbe ignore hobe.

        
dhoro
Notun variable banao.

        
bolo
Output dekhao. Comma diye onek kichu dewa jay.

        
jodinahole jodinahole
Shorto mille ki hobe, na mille ki hobe.

        
jotokkhon
Shorto thik thakle loop cholte thake.

        
protimoddhe
Gona loop, ba talika/lekha-r prottek ta jinis dhore loop.

        
kajferot
Nijer function banao, ar kaj shesh hole value fire pao.

        
[ ]
Talika (list): [1, 2, 3], a[0], jogkoro, doirgho.

        
thamoporerta
Loop bhango, ba ei dhap chhere porer dhape jao.

        
thikbhulkhali
Sotti, mittha, ar kichui na.

        
+ - * / %== != < > <= >=&& || !+= -= *= /=
Hishab, tulona, jukti ar shortcut.
